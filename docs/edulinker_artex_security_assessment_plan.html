1 개요 및 추진 배경

edulinker.io는 한국 초·중·고등학교를 위한 통합 자동화 플랫폼으로, 메인 허브, 학생 계정 배포(sendipass), 전자서명(sign-school), 가정통신문(gatong) 등 학생·학부모·교사의 민감 정보를 다루는 대규모 서비스입니다.

핵심 검증 목표 1

완전 격리 환경 모사

운영망 및 외부 인터넷과 100% 분리된 안전한 테스트베드

핵심 검증 목표 2

RBAC / 권한 체계 검증

학생 계정의 교사 권한 탈취 및 타인 성적·비번 열람 방지

핵심 검증 목표 3

자율 침투(ARTEX) 적용

LLM 에이전트 기반 공격 표면 정찰 및 제로데이 탐색

⚠️ 법적 및 운영 안전 준수 사항 본 테스트는 서면 승인된 인가 범위 내에서 전용 격리 브리지망에서만 실행되며, 실제 운영 데이터나 개인정보는 절대 사용하지 않고 100% 가상 합성(Faker) 데이터를 사용합니다.

3 내부 격리 모사 환경 구축 방안

외부 공용 인터넷과의 연결을 전면 차단(internal: true)하는 전용 Docker 브리지 네트워크를 구성하여 안전하고 재현 가능한 테스트베드를 배포합니다.

격리 인프라 구성 파일 (compose.simulation-env.yml)

version: '3.8'

networks:
  edulinker-isolated-net:
    driver: bridge
    internal: true # 외부 인터넷 아웃바운드/인바운드 전면 차단
  artex-mgmt-net:
    driver: bridge # ARTEX의 LLM 호출 및 웹 UI 접속용 분리망

services:
  # 1. edulinker PostgreSQL 데이터베이스
  edulinker-db:
    image: postgres:16-alpine
    networks:
      - edulinker-isolated-net
    environment:
      POSTGRES_USER: edulinker
      POSTGRES_PASSWORD: test_secure_password_123
      POSTGRES_DB: edulinker

  # 2. Redis 캐시
  edulinker-redis:
    image: redis:7-alpine
    networks:
      - edulinker-isolated-net

  # 3. Wasabi S3 Mock (MinIO)
  edulinker-s3-mock:
    image: minio/minio:latest
    networks:
      - edulinker-isolated-net
    command: server /data --console-address ":9001"
    environment:
      MINIO_ROOT_USER: mock_s3_admin
      MINIO_ROOT_PASSWORD: mock_s3_password_123

  # 4. 외부 알림 가상화 (Mailpit)
  edulinker-mailpit:
    image: axllent/mailpit:latest
    networks:
      - edulinker-isolated-net

  # 5. edulinker Core Apps (Main Hub, Sendipass, API)
  edulinker-app:
    build:
      context: /Users/nm/works/project2025/edulinker
      dockerfile: Dockerfile.staging
    networks:
      - edulinker-isolated-net
    environment:
      NODE_ENV: test
      DATABASE_URL: postgres://edulinker:test_secure_password_123@edulinker-db:5432/edulinker
      REDIS_URL: redis://edulinker-redis:6379
      S3_ENDPOINT: http://edulinker-s3-mock:9000
      SMTP_HOST: edulinker-mailpit
      SMTP_PORT: 1025
    depends_on:
      - edulinker-db
      - edulinker-redis
      - edulinker-s3-mock

  # 6. ARTEX 자율 침투 테스트 엔진
  artex-scanner:
    image: ghcr.io/jiwoochris/artex-global:latest
    networks:
      - edulinker-isolated-net # 대상 시스템 침투용 내부망
      - artex-mgmt-net         # 관리자 UI 및 LLM 통신용
    ports:
      - "127.0.0.1:8787:8787"
    environment:
      ARTEX_PG_DSN: postgres://artex:artexpass@artex-db:5432/artex?sslmode=disable
      ARTEX_LANG: ko
      OPENAI_API_KEY: ${OPENAI_API_KEY}

  • Super Admin: superadmin / superadmin2025 (시스템 최고 관리자)
  • 학교 관리자: admin@yongmun.school / admin123 (용문초 관리자)
  • 교사 계정 풀: teacher1@yongmun.school ~ teacher10

4 ARTEX 침투 테스트 플랫폼 설정

ARTEX의 LLM 멀티 에이전트가 최적의 진단 성능을 발휘할 수 있도록 타깃과 실행 옵션을 구성합니다.

  • 타깃 등록 (In-Scope): http://edulinker-app:3000 (메인 허브), http://edulinker-app:3002 (Sendipass), http://edulinker-app:5173 (데스크톱 웹)
  • 출력 언어: ARTEX_LANG=ko (취약점 리포트, PoC 요약, 조치 권고사항 국문 자동 생성)
  • 테스트 모드:
    • 블랙박스 (Black-box): 인증 정보 미보유 상태에서 정찰(Recon) 및 인증 전 취약점 점검
    • 그레이박스 (Gray-box): 학생/학부모/교사 JWT 토큰을 사전 주입하여 수평/수직 권한 상승 및 BOLA 점검

5 중점 침투 점검 시나리오

    autonumber

    participant DB as PostgreSQL (Prisma)

    A->>W: 학생 계정(student1) 세션 획득
    A->>API: 교사 전용 결재/가통 작성 tRPC 프로시저 호출

    alt 권한 검증 누락
        API->>DB: 불법 상태 변조 성공 (취약점 확인)
        DB-->>A: 200 OK (ARTEX Critical Finding 기록)
    else 권한 정상 차단
        API-->>A: 403 Forbidden
    end

    Note over A,DB: 시나리오 2: Sendipass 학생 자격증명 노출 점검
    A->>W: Sendipass 파라미터 Fuzzing (타 학생 ID 변조)
    W->>API: Object ID 변조 요청 전송
    API-->>A: 타 학생 비밀번호 노출 여부 점검 (IDOR 탐지)

점검 영역별 세부 체크리스트

점검 영역 상세 점검 내용 예상 취약점 심각도
인증 및 인가 (Auth & RBAC) 학생 세션으로 교사/관리자 전용 tRPC 프로시저 호출 시도, 타 학교 테넌트 데이터 접근 시도 BOLA, IDOR, 수평/수직 권한 상승 Critical
Sendipass 계정 배포 학생 비밀번호 배포 파라미터 조작, 무차별 대입(Brute-force) 및 인증 전 자격증명 조회 자격증명 대량 탈취, 인증 우회 Critical
전자서명 (sign-school) 타인의 서명 덮어쓰기, 위조된 서명 토큰 주입, 서명 문서 상태 강제 변경 서명 부인 방지 실패, 문서 변조 High
API & 입력값 검증 tRPC 파라미터 Zod 스키마 우회, Prisma $queryRaw SQLi, XSS 페이로드 주입 SQL Injection, Stored XSS High
파일 업로드 & 스토리지 웹셸 확장자 우회 업로드, MinIO Path Traversal, 권한 없는 파일 직접 다운로드 RCE, 비인가 파일 열람 High
실시간 통신 (Socket.IO) 비인가 채널/Room 임의 Join, 웹소켓 패킷 변조 및 실시간 메시지 도청 WebSocket Hijacking, 메시지 유출 Medium
민감정보 노출 (PII) API 응답 내 불필요한 주민번호/전화번호 포함 여부, 에러 시 스택트레이스 노출 개인정보보호법 위반, 정보 누출 Medium

6 안전 통제 및 리스크 관리 대책

  • 네트워크 100% 격리: Docker 네트워크 옵션 internal: true 적용으로 외부 인터넷 유출 절대 차단
  • 원클릭 롤백 스크립트: 침투 공격 중 DB 파손 시 즉시 원복: 
    docker compose -f compose.simulation-env.yml exec edulinker-app pnpm db:reset --force
  • 비용 및 토큰 통제: ARTEX의 일일 LLM 토큰 상한선을 설정하여 예기치 않은 과금 방지
